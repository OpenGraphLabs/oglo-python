**이번 9월 19~22일 조사는 A5의 USB 전송·저장 경로를 중심으로 했고, A1과 B12의
일부를 확인했다. A 전체의 유닛 전수 합격이나 센서 물성 검증은 아니다.**
대상은 조사에 사용한 장갑과 고정한 펌웨어·SDK·호스트 조건이다.
“확인”은 그 범위의 증거가 있다는 뜻이며 모든 생산 유닛의 합격을 뜻하지 않는다.

## A5 카운터의 정확한 범위

마지막 밤샘 원본 `meta.json`의 STATUS 시작→종료 값이다. 누적값과 이번 전후 증분을 구분한다.

| 카운터 | L-00003 | R-00028 |
| --- | ---: | ---: |
| tag_dropped | 0 → 0 | 0 → 0 |
| tag_short_writes | 0 → 13,008,614 | 0 → 17,128,098 |
| deadline_misses | 19 → 19 | 20 → 20 |
| loop_us_max | 3,172 → 3,418 | 3,188 → 3,532 |
| tx_stall_count | 1 → 6 | 1 → 1 |
| tx_stall_max_ms | 14,603 → 14,603 | 15,435 → 15,435 |
| wedge_recoveries | 0 → 0 | 0 → 0 |

`tag_short_writes`는 해당 펌웨어의 재시도 카운터로 실제 샘플 누락과 따로 본다.
왼손 `tx_stall_count`는 5 증가했다. 이 전후 스냅샷만으로 각 이벤트 시각이나
녹화 시작/종료 전환과의 관계까지 정하지 않았다. `tx_stall_max_ms`의 14.603/15.435초는
시작 때부터 있던 값이므로 밤샘 도중 그 길이만큼 끊겼다고 해석하면 안 된다.
저장 프레임의 최대 호스트 시각 간격은 왼손 60.171 ms, 오른손 57.383 ms이며
순번 누락은 0이다. 따라서 “전체 수신 정지·샘플 누락 0”과 “모든 stall 카운터 0”은 다르다.

## B. 샘플 특성화

- **B1~B11 미검증:** 힘-출력·히스테리시스·반복성·계단 응답·크리프·제어 온습도
  드리프트·공간 특성·고정 힘 유닛 간 편차·재료/로트·장착 preload·기계 내구도는
  이번 USB/SDK 시험에서 측정하지 않았다. 여러 유닛의 USB 비교는 고정 힘 감도 편차 시험이 아니다.
- **B12 일부 확인:** USB 장시간 수신은 완료했다. 관측 온도 59.5°C는 **Pi 호스트의 온도**이며
  장갑 리더보드의 발열 측정이 아니다. 배터리 사용 시간·충전 사이클도 검사하지 않았다.
- **B13·B14 미검증:** 여러 쌍 BLE 동시 운용·ESD 시험 및 실물 TVS 확인은 하지 않았다.

## C. 검사 기록과 박스

- **기록 일부 있음:** 이번 대상 유닛의 serial·USB ID·펌웨어 해시·시각·설정/zero·상태값,
  원본 수신·저장 파일·검증 결과·스크립트/패키지 해시는 이미 있다. “유닛별 기록이 하나도
  없다”는 표현은 이번 USB/SDK 조사에는 맞지 않는다. 다만 WHO_AM_I·배터리·프로브 측정과
  박스 버전을 포함하는 **생산 유닛 전수검사 기록**은 갖추지 못했다.
- **박스 재현성 미검증:** FFC 재장착과 고정 힘/각도 반복으로 검사기 자체의 편차를 측정하지 않았다.
- **합격선 일부만 존재:** 이번 수신 조사에는 순번 손실 0·필수 센서 수신·새 drop/deadline 0 등
  검사 기준을 사용했다. 이것은 A4/B의 감도·간섭·훼손에 대한 생산 합격선이 아니다.
  SWEEP spread를 기계적 손상이나 감도 균일도의 합격선으로 검증하지 않았다.
- **HW2 미검증:** SYNC+PALM 실물의 동기 입력·팜 채널 검사를 하지 않았다.

`imu_ok=false`와 `mag_ok=false`가 동시에 나온다는 사실만으로 버스 단락을 확정하는
합불 규칙을 만들면 안 된다. 이번 검사는 그 원인을 단락으로 구별하는 검증을 하지 않았다.
공통 버스·전원·초기화 이상을 조사할 신호와 단락 확정은 구분해야 한다.

기존의 200 Hz IMU 새 값 관측과 다른 날짜의 현장 정확도 추정은 이번 0.9.17 장갑별
ODR·WHO_AM_I·물리 정확도 검사의 대체로 옮겨 적지 않았다.
